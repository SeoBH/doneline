Doneline에서 끝내세요.

고객사 직원은 휴대폰으로 요청하고, 엔지니어는 한 화면에서 맡아 처리하고, 고객은 결과를 확인합니다. 월말 보고서는 엑셀 한 번으로 끝납니다.

  • 요청이 흩어져 있습니다 메신저, 전화, 메일로 들어온 요청을 누군가 기억하고 있어야 합니다.
  • 누가 언제까지 하는지 모릅니다 담당자가 정해졌는지, 급한 건이 밀려 있는지 한눈에 보이지 않습니다.
  • "처리했는데요" "아직 안 돼요" 끝났다는 업체와 아니라는 고객 사이에서 확인이 오갑니다.
  • 월말 보고서에 하루가 갑니다 고객사별 처리 건수와 시간을 엑셀로 다시 정리합니다.

요청 접수부터 월간 보고까지, 한곳에서

고객사 전용 가입 링크

고객사마다 가입 링크를 보내면 직원들이 직접 가입합니다. 승인과 부서 지정은 업체나 고객사 관리자가 한 번에 끝냅니다.

휴대폰으로 요청 등록

고객은 앱 설치 없이 휴대폰 브라우저에서 요청을 올리고 진행 상황과 답변을 봅니다.

단계별 처리와 담당 규칙

접수 → 처리 중 → 확인 대기 → 완료. 맡은 사람만 진행하고, 재배정은 관리자만 합니다. 내부 메모는 고객에게 보이지 않습니다.

SLA 기한 자동 계산

우선순위별 첫 응답·처리 기한을 업체가 정하면 요청마다 기한이 붙고, 넘긴 요청은 목록에서 바로 드러납니다.

고객 확인과 자동 완료

완료는 고객이 확인해야 확정됩니다. 7일 동안 확인이 없으면 자동으로 완료되어 요청이 끝없이 열려 있지 않습니다.

월간 리포트 엑셀

고객사별 등록·처리·확인 건수, SLA 준수율, 평균 처리 시간을 보고 엑셀로 바로 내려받습니다.

알림

새 요청, 배정, 처리 완료, 재처리 요청을 앱 안 알림으로 받고, 이메일 인증을 마친 계정은 메일로도 받습니다.

업체별 데이터 분리

업체마다 데이터가 데이터베이스 단계에서 분리되어 다른 업체에는 보이지 않습니다. 모든 변경은 감사 기록으로 남습니다.

고객은 휴대폰으로 확인하고, 관리자는 숫자로 봅니다

오늘 바로 시작하는 방법

  1. 업체 가입 업체 이름과 관리자 정보만 입력하면 바로 로그인됩니다.
  2. 고객사 등록 고객사·법인·부서를 등록하고 고객사 가입 링크를 복사해 보냅니다.
  3. 고객이 요청 고객사 직원이 링크로 가입하고, 승인되면 휴대폰으로 요청을 올립니다.
  4. 처리하고 보고 엔지니어가 맡아 처리하고, 월말에는 리포트를 엑셀로 내려받습니다.

처음 화면에 단계별 시작하기 안내가 나오고, 사진·영상이 있는 사용 설명서로 혼자서도 설정할 수 있습니다.

자주 묻는 질문

나중에 요금이 생기나요?

현재는 모든 기능을 무료로 쓰실 수 있습니다. 앞으로 요금제가 생기면 시작 30일 전에 먼저 알려 드리고, 동의하신 경우에만 적용됩니다.

프로그램을 설치해야 하나요?

아니요. PC와 휴대폰의 웹 브라우저에서 바로 씁니다. 고객사 직원도 앱 설치 없이 가입 링크로 들어옵니다.

다른 업체가 우리 데이터를 볼 수 있나요?

볼 수 없습니다. 업체마다 데이터가 데이터베이스 단계에서 분리되어 있고, 고객사 직원은 자기 부서의 요청만 봅니다. 비밀번호는 되돌릴 수 없는 형태로만 저장해 운영자도 알 수 없습니다.

고객이 완료 확인을 안 누르면 어떻게 되나요?

처리 완료 후 7일 동안 확인이 없으면 자동으로 완료됩니다. 월간 리포트에는 고객 확인 완료와 자동 완료가 따로 집계됩니다.

도입할 때 도움을 받을 수 있나요?

첫 화면의 시작하기 안내와 사진·영상 설명서로 혼자서도 설정할 수 있습니다. 막히는 부분은 앱 오른쪽 위 개선 요청 버튼이나 아래 메일로 알려 주세요.

필요한 기능이 없으면요?

앱 안의 개선 요청으로 보내 주세요. 보내 주신 의견은 모두 읽고 다음 개선 순서를 정하는 데 씁니다.
